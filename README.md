# Advanced Calculator

A responsive calculator built with HTML, CSS, and JavaScript. It includes:

- Basic arithmetic operations
- Scientific functions such as `sin`, `cos`, `tan`, `sqrt`, `log`, and `ln`
- Power, absolute value, trigonometric inverse functions, and constants
- Memory controls: clear, read, add, subtract, and save
- Keyboard input and calculation history
- Light and dark themes
- Responsive layout for mobile and desktop

## Run locally

Open `index.html` in a browser.

## Test

```bash
node --test calculator-core.test.mjs
```
